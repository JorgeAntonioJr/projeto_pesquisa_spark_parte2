Projeto Spark - Trabalho 2

Definição Oficial e Histórico

O Apache Spark é um framework de código aberto voltado para a computação distribuída (processamento paralelo) de dados massivos (Big Data). * Origem: Criado em 2009 na Universidade de Berkeley, o projeto passou para a Apache Software Foundation em 2014, tornando-se um dos maiores ecossistemas de processamento de dados do mundo. * Modelo de Processamento: Utiliza o processamento em memória através de RDDs (Resilient Distributed Datasets), o que garante tolerância a falhas e alto desempenho em pipelines analíticos. * Ecossistema de Linguagens (Spark API): Suporta linguagens como Python, Scala, Java, SQL e R.

Arquitetura do Apache Spark Core

O ecossistema é modular e construído sobre o núcleo Spark Core, englobando: * Spark SQL: Módulo para processamento de dados estruturados e semi-estruturados com consultas SQL. * Spark Streaming: Motor escalável para processamento de fluxos de dados em tempo real. * MLlib (Machine Learning): Biblioteca distribuída de aprendizado de máquina. * GraphX (Graph): API para computação em grafos.

O Papel do PySpark e o Mercado

O PySpark é a colaboração entre o Apache Spark e o Python. * Databricks: Criada em 2013 pelos fundadores do Spark na Berkeley, é a maior colaboradora do projeto e a plataforma PaaS/SaaS de processamento de dados mais utilizada no mercado. * Plataformas de Nuvem: Outras soluções gerenciadas incluem Amazon EMR, Google Cloud Dataproc, Azure Synapse Analytics e Azure HDInsight.
